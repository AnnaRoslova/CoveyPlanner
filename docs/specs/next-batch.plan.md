## NB2. Дело на дело = шаг (N2.1–N2.7)

  на само тащимое; проверка «у тащимого есть шаги» — в `DragDropService` до броска, иначе бросок уходит в порядок).

  (запомнить день/позицию или категорию/позицию до броска).
- Спека tasks-steps-done.md: снять пункт «не делаем» (дело на дело).
- Тесты: API на запреты (уже есть S7/R; добавить «на занятие»), e2e `dnd-make-step.mjs`; прогон `dnd*`, `steps*`, `feed*`.
- **Остановка: ручная проверка Анной** (перетаскивание).

## NB3. Отчёт за период (N5.1–N5.7)
- Core: `ReportService` — серии (план по нормам недель с четвергом в периоде, факт по скрепкам с днём в периоде, вкл. `ClipSeriesId`), разовые цели одной
  строкой, «Выполненное» по категориям за период; без записи и без генерации недель.
- Server: `GET /api/report`, `GET /api/report.csv` (UTF-8 BOM, «;», CRLF, экранирование).
- Client: кнопка «📊» в шапке недели, экран «Отчёт» (периоды, стрелки, «свой»), «Скачать CSV».
- Тесты: unit `ReportService` (границы периода, четверг, правка нормы, скрепки удалённых целей), API (JSON + CSV: BOM, разделитель, кавычки), e2e `report.mjs`.
- **Остановка: ручная проверка Анной** (числа на её данных — на копии).
