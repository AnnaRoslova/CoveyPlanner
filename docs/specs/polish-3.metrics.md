⚠ Решила сама (решения Анны — в спеке как есть):

- C5: открытие — месяц показанной недели вверху ленты; лента ± полгода, дальше дорастает по полгода.

- S4: «Вернуть» на плашке возвращает «выполнено»; «Отменить пропуск» потом — дело открыто.
- R1: пресеты повтора — названием («будни»); R2: дни занятий в шапке окна остаются у цели без выбранных дней.
