## Этап 7. Лента: галочка, плашки, проекты

- Отметить мысль в ленте → мысль исчезла; у значка корзины плашка «„…“ выполнено · в корзину · вернуть», значок корзины не закрыт.
- «вернуть» на плашке → мысль снова на своём месте в категории.
- Отметить мысль → «в корзину» → в корзине; вернуть из корзины → не в ленте, а в «✓ выполненное».
- Удалить мысль перетаскиванием на корзину → плашка «Удалено … · Вернуть» над значком корзины.
- Поиск в ленте по названию шага → проект найден и раскрыт, шаг подсвечен *(после N6 — см. там: проекты ищутся в «🛠 Проекты»)*.
- Шаг из дня (после N6 проектов в ленте нет) бросить в категорию ленты → стал мыслью там, плашка «больше не шаг «…» · Вернуть»; «Вернуть» → снова шаг.
- У длинных записей со шагами «⌄» не наезжает на пилюли «~1,5 ч».

## Этап 8. Окно дела: «Проект», шаги

- Окно мысли → поле «Проект» → начать вводить название → выбрать → «Сохранить» → мысль ушла из ленты, стала шагом проекта.
- В окне шага сверху «↳ Ремонт» → клик → окно проекта.
- У проекта поле «Проект» неактивно с подсказкой.
- В окне проекта блок «Шаги ☑ N/M»: добавить шаг Enter, отметить, переименовать, перетащить шаг в день недели (окно бледнеет) → у шага метка дня.
- 🗑 при наведении на шаг в окне → шаг в корзину, «Вернуть» на плашке возвращает.
- У книги с занятиями «Чтения» → строка «N занятий ▸» → раскрывается списком «Чт 1 окт · Чтение».
- Esc закрывает окно и после перетаскивания из него.

## Этап 9. «✓ выполненное»

- Внизу ленты, слева от корзины, «✓ выполненное» → экран поверх недели.
- Отмеченная мысль — в группе своей категории, в заголовке «2026 · N», дата — день отметки.
- Дело, созданное прямо в неделе и отмеченное, — его там нет; мысль, перенесённая в день и отмеченная там, — есть.
- Снять галочку на экране → дело пропало с экрана и вернулось в ленту на своё место (или открытым в свой день).
- У проекта «N шагов · N недель» → клик раскрывает шаги.
- Клик по названию → окно дела; Esc или крестик закрывают экран.
- Удалить категорию («Переложить в неразобранное») → её выполненные дела — в группе «без категории» в конце.

## Этап 10. Проект в окне цели, скрепки удалённой цели, CLAUDE.md

- Окно постоянной цели «Чтение» → «Проект: Атомные привычки» → бросить цель на день → занятие стало шагом книги (под ним «☑ …», «↳» нет).
- Следующая неделя → у цели тот же проект; сменить на «— нет» → старые занятия остались шагами книги, новые — без проекта.
- Книгу отметить выполненной → в окне цели в поле «Проект» пометка «(выполнен)», новые занятия — без проекта.
- Привычка: на прошлой неделе отметить галочкой цели (без дня) → удалить цель «Только на этой неделе» → дело в понедельнике той недели, выполнено;
  счёт 🫙 не уменьшился.
- Темы (особенно Обсидиан): «↳», «☑ N/M», чекбокс ленты, экран «Выполненное» читаются.
- ⚠ решила сама: «✓ выполненное» — тихая строка (контраст 3:1, как «+ категория»), а не обычный текст.

## N1. Подсветка неразложенного

- Цель «2 раза» без занятий в днях → строка цели слева с мягкой розоватой подложкой и тонкой полоской слева; навести → «не разложено: 2 из 2».
- Бросить цель на день → «не разложено: 1 из 2»; на второй день → подсветка исчезла.
- Занятие убрать в корзину (🗑 в дне) → подсветка вернулась; «Вернуть» → исчезла.
- Галочка у цели (выполненное без дня) закрыла норму → подсветки нет.
- «Свернуть все цели» → у свёрнутых подсветка и подсказка остаются.
- Прошлая неделя → подсветки нет ни у одной цели.
- Темы (особенно Обсидиан): подсветка заметна, но не кричит; текст цели и процент читаются.
- ⚠ решила сама: подсветка есть и у будущих недель (их план тоже можно «собрать»); есть только 4 темы из 11 — подсветка проверена в них
  (у остальных тем значения возьмутся из их акцентного цвета, когда темы появятся).

## N2. Дело на дело = шаг

- Дело из дня тащить на **середину** другого дела → строка подсвечена, подпись «сделать шагом «…»» → отпустить: дело стало шагом
  («↳ …» под ним, у проекта «☑ 0/1»), плашка «„…“ теперь шаг „…“ · Вернуть». «Вернуть» → снова отдельное дело на прежнем месте.
- Тащить на **верхний/нижний край** строки → линия вставки, обычный порядок; шагом не становится.
- Мысль из ленты на середину другой мысли → та стала проектом (ушла в «🛠 Проекты»), плашка с «🛠 Проекты · Вернуть»;
  «Вернуть» → обе мысли на своих местах.
- На занятие цели, на шаг, проект на другое дело → середина не подсвечивается, шагом не становится.
- Шаг из дня на строку **своего** проекта → подпись «снять с дня — в список шагов» → шаг снят с дня, остался шагом.
- Шаг из раскрытого списка проекта в «🛠 Проекты» на другой проект → стал шагом того проекта.
- ⚠ решила сама: подпись «сделать шагом «…»» — на подсвеченной строке (как «сделать занятием этой цели» у целей), а не у призрака.
- ⚠ решила сама: в ленте середина мысли теперь «сделать шагом», порядок мыслей — только у верхнего/нижнего края строки.

## N5. Отчёт за период

- «📊» в шапке недели (справа от 🫙) → экран «📊 Отчёт», по умолчанию текущий месяц («Октябрь 2026»).
- Строки привычек и постоянных целей: «факт / план», процент, у привычек 🔥N или ⚠; ниже «разовые цели: камней N, выполнено M».
  Сверить пару чисел с ощущением: «Бег» за месяц — сколько раз реально отмечен.
- «Выполненное»: «📚 Книги — 3: Дюна, …» — только отмеченное в этом периоде.
- «неделя», «N месяцев» (выбор 2–12), «год», «свой» (две даты) → числа меняются; стрелки ‹ › листают.
- «Скачать CSV» → файл «CoveyPlanner-отчёт-…csv» открывается в Excel двойным щелчком: кириллица цела, колонки разделены.
- Пустой период («свой» в будущем) → «За этот период ничего нет.»; CSV всё равно скачивается с заголовками.
- ⚠ решила сама: план считается только по целям, которые уже есть (у постоянной цели будущие недели появляются, когда их открывают),
  поэтому у текущего месяца план — по прошедшим и открытым неделям.
- ⚠ решила сама: скрепки удалённой цели входят в факт, а норма у недели без цели — 0 (процент может быть больше 100 → «100% ✓»).

- «в ленту» → дело в ленте; «в корзину» → плашка «в корзине · Вернуть» (Ctrl+Z тоже работает); «оставить» — строка бледнеет, дело на месте.
- Камень разовой цели → «на след. неделю» → на следующей неделе та же цель с этим занятием. У постоянной цели кнопки переноса нет.
- «Дальше» → привычки (сколько из нормы, 🔥), давно лежащие мысли, миссия (пока — список ролей, миссия — этап 9), камни следующей недели:
  за экраном видно следующую неделю, «у роли «Дом» нет камней», «+ цель» → цель появилась. «Назад» — снова текущая неделя. «Готово» — следующая неделя.
- В воскресенье после 12:00 при открытии — плашка «Неделя заканчивается · Недельный обзор» (один раз; если пропустили — в понедельник до 12:00).

## batch-ux, этап 9. «Моя миссия»

- «⚙ Настройки → ✦ Моя миссия» → пустое поле с подсказкой «Начни с конца: кем ты хочешь быть?». Написать пару строк (Shift+Enter не нужен — Enter переносит строку).
- У ролей — строки «кем я хочу быть в этой роли…»; заполнить «Работа». Закрыть, перезагрузить — всё на месте, переносы строк тоже.
- Навести на название роли «Работа» слева → подсказка «спокойным профессионалом · свернуть цели роли». Окно роли («⋯») — то же поле.
- «⚙ Настройки → Миссия: показывать вверху левой панели» → вверху панели «✦ Моя миссия ▸»; клик — текст и «изменить»; после перезагрузки раскрытие помнится.
- Недельный обзор (W) → шаг 4 «Миссия» — текст и строки ролей, «изменить» открывает «Мою миссию».
- ⚠ решила сама: «кем я хочу быть» есть и у измерений пилы (Тело, Ум…), не только у обычных ролей.
- ⚠ решила сама: блок в панели по умолчанию свёрнут; раскрытие помнит браузер, а включение блока — сервер (настройка).
