## FA. Привычка ≠ проект (A1–A4)
- Core: `GoalService.AddStepAsync` — у постоянной цели без проекта (или с проектом в корзине) — `DomainException` (A1); `StepService.AddAsync`
  для занятия идёт туда же.
- Client: `GoalStepsBlock` — у постоянной цели без проекта не показывается (окно цели — по переключателю окна, окно занятия — по цели), подсказки A2/A2a;
  «(в корзине)» в поле «Проект» (A2b).
- Миграция `HabitsAreNotProjects` (A3): данные по правилу спеки; тест миграции (`MigrationTests`): авто-проект привычки — отвязан и в корзине,
  книга с другим названием и проект с настоящим шагом — не тронуты.
- Тесты: API `HabitNotProjectApiTests` (A1, A2), правка тестов G1/G7 под явный проект у постоянной цели; e2e `goal-steps`, `goal-project`.
- **Остановка A3:** миграция на копии базы, отчёт Анне до изменений; установка — после её ответа.
