## Этап 0. Общие детали (Common)
- `MoreBlock` («Подробнее ▾» / группа: заголовок-кнопка, перечень «ещё: …», показ только заполненных полей) и `MoreMenu` («⋯»: пункты, черта,
  опасный, недоступный с причиной, подменю; на `Popover`, Esc — только меню).
- `DateField` (дата + меню быстрых вариантов + «другая дата…»), квадрант — `ChoiceField` вместо `QuadrantPicker` в окнах.
- Строка «МЕТКА · значение» в `editor.css`; контраст новых элементов в `themes-contrast.mjs`.

## Этап 1. Окна (U2)
- `TaskEditor` (дело, шаг, занятие), `SomedayTaskEditor` (мысль), `GoalEditor` (группы «Основное», «Повтор и расписание», «Подробнее»),
  маленькие окна (U2-e). `NextWeekButton` → пункт «⋯» с подменю ролей.
- e2e: правка сценариев из списка спеки; новый `declutter.mjs` (окна).

## Этап 2. Левая панель (U1)
- `RoleCard`: название — кнопка, «▾/▸», свёрнутое состояние (новое `RoleFoldState`, в браузере), розовая точка; пила — U1.3;
  «⋯» и «+ цель» — при наведении; шапка — U1-a. dnd.js: раскрыть свёрнутую роль при задержке (U1.5).
- e2e: `goal-fold`, `roles`, `dnd-goals`, `next-week` (B4 «Показать» раскрывает роль); `declutter.mjs` (панель).

## Этап 3. Остальное (U3)

- e2e: `themes`, `feed-tools`, `report`, `habits`, `done-screen`, `day-layout`; контраст — все темы.
