# План: дела, шаги и «Выполненное»

Статус: **черновик**. Начинать только после «ок» Анны на [tasks-steps-done.md](tasks-steps-done.md) и ответов на открытые вопросы.
Ответы на вопросы, отличные от «предлагаю», сначала вносятся в спеку, потом план правится.

Правила каждого этапа:
- в конце этапа `dotnet build` без ошибок и `dotnet test` зелёный; отдельный коммит, в сообщении — номера правил (`S12, S13`);
- этапы 1–5 не меняют интерфейс (сервер обратно совместим с текущим клиентом), поэтому их можно ставить по одному;
- после этапов с перетаскиванием (6, 7) — остановка на ручную проверку Анной с чек-листом;
- установка на рабочий сервер — только с бэкапом (`tools/backup.ps1`), миграция сначала прогоняется на копии базы.

## Этап 1. Модель и миграция
- `TaskItem`: `IsFromSomeday` (ставится в `CreateSomeday` и `MoveToSomeday`), `StepOrder`.
- `GoalSeries`: `IsHabit`; `IsHabitDeleted` убрать (`DeleteHabit` → `IsHabit = false` + сброс банки; `RecurFrom` больше не трогает флаг).
- EF-миграция `TasksStepsDone` (спека 4.2), индекс `(State, IsFromSomeday, CompletedAt)`.
- `HabitService`: привычка = `IsRecurring && IsHabit` — поведение для данных Анны не меняется (все серии пилы получают `IsHabit = 1`).
- Тесты: `MigrationTests.TasksStepsDone_*` (база со схемой `HabitsAreSeries`, числа как в 4.3), `HabitEntityTests` под новый флаг.
- Проверка: миграция на свежей копии базы Анны — 14 выполненных из ленты, 8 серий `IsHabit = 1`, экран 🫙 тот же (`GET /api/habits` на копии до/после).

## Этап 2. «🫙 копить» (H1′–H9′)
- `GoalChanges` / `UpdateGoalRequest` + `IsHabit`; предустановка при включении «каждую неделю» (H2′) — на клиенте в окне, сервер хранит присланное;
  при создании постоянной цели без явного значения — по правилу H2′.
- `EfHabitRepository.GetClipsAsync` без `ParentId == null` (H9′).
- `HabitService.GetOverviewAsync`: группировка по первой роли (H8′) — `HabitOverview.GroupRole` вместо `SawRoles[0]`.
- UI: переключатель в `GoalEditor`, группы обычных ролей в `HabitsScreen`, пилюля у любой цели-привычки.
- Тесты: unit + API (H1′–H8′); e2e `habits.mjs` п. 17–19.

## Этап 3. Шаги — ядро (S1–S18, S23–S28)
- `TaskItem.SetParent(parent?)` с проверками S1/S7; `CreateStep` — роли копией (S5), `StepOrder` в конец.
- `ProjectRules` (чистые функции): сводка проекта (шаги в счёте / занятия), автоотметка и снятие (S12–S15, S17).
- `TaskService`: `SetDoneAsync` применяет S12–S14 и возвращает изменённого родителя; `SetParentAsync` (S8–S10, S14);
  `TrashAsync`/`RestoreAsync` проекта (S23–S26); `GoalRemover` — S28.
- Репозиторий: запросы дней (`GetPlannedAsync`, `GetUntimedOnDayAsync`) **включают шаги**; `GetStepsAsync` — по `StepOrder`; шаги родителей для недели и ленты.
- Тесты: unit на каждое правило S и крайние случаи К1–К3, К7–К11, К16–К19; API на перенос шага в день и на другую неделю.

## Этап 4. Отметка в ленте и «Выполненное» — ядро (D, V)
- `TaskItem.Complete` разрешён в ленте (D2), `Uncomplete` «выполненного в ленте» → `Someday` на прежнее место / наверх «неразобранного» (D6).
- `DoneArchiveService` + `GET /api/done` (V1–V6): группы, счёт по годам, «N шагов · N недель · N занятий».
- `CategoryService.DeleteAsync`: в вопросе считаются только мысли ленты; выполненные остаются (К13).
- Тесты: unit (D2, D6, V1–V6, К12, К13, К20, К21) и API.

## Этап 5. API и DTO
- `TaskDto` + `ParentId`, `ParentTitle`, `IsFromSomeday`, `StepOrder`, `Project`; `GET /api/week` и `GET /api/someday` — шаги (спека 5).
- `PUT /api/tasks/{id}/parent`, цель броска `StepList`, `PUT /api/tasks/{id}/steps/order`; `DELETE /api/steps/{id}` — убрать (клиент перевести на корзину в этапе 8).
- Клиент компилируется и работает как раньше (новые поля пока не показываются). Тесты API.

## Этап 6. День: проекты и шаги в днях (UI, перетаскивание)
- Строка родителя `▸ Ремонт ☑ 2/5`, раскрытие (localStorage), строка шага с `↳ Ремонт`, «+ шаг» в раскрытом списке.
- Перетаскивание шагов: список → день / неделя / цель; на строку родителя (S20).
- **Остановка: ручная проверка Анной** (чек-лист: перенос шага между днями, на другую неделю, на родителя, галочка синхронна, сумма дня).

## Этап 7. Лента: галочка, плашки, проекты
- Чекбокс у строк (D1), плашка «выполнено · в корзину · вернуть» (D3), раскрытие родителя, бросок шага в ленту (S21) с плашкой.
- Поиск по шагам. «✓ выполненное» внизу ленты.
- **Остановка: ручная проверка Анной** (перетаскивание из ленты, отметка, «вернуть», поиск).

## Этап 8. Карточка дела
- Поле «Проект» (выпадающий список с поиском), неактивное у дела с шагами.
- Список шагов: метка дня, клик — карточка шага, порядок перетаскиванием, без «×» (в корзину — из карточки шага), «12 занятий ▸».
- Шапка «↳ Ремонт» у шага.

## Этап 9. Экран «Выполненное»
- Экран поверх недели (как «Копилки»): группы, годы, строки, раскрытие шагов, снятие галочки, карточка.
