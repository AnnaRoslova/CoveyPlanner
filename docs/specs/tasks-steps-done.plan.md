## Этап 3. Шаги, проект цели, скрепки удалённых целей — ядро (S, P, C)
- `TaskItem.SetParent(parent?)` с проверками S1/S7; `CreateStep` — роли копией (S5), `StepOrder` в конец.
- `ProjectRules` (чистые функции): сводка проекта (шаги в счёте / занятия), автоотметка (S12, S15, S17; сам родитель не открывается — S13).
- `TaskService`: `SetDoneAsync` применяет S12 (только отметка, S13) и возвращает изменённого родителя; `SetParentAsync` (S8–S10);
  `TrashAsync`/`RestoreAsync` проекта (S23–S26); `GoalRemover` — S28 и C1–C4 (выполненное занятие без дня → понедельник недели цели, `ClipSeriesId`; скрепки — и по `ClipSeriesId`).
- Проект в шаблоне цели (P1–P9): `GoalChanges` + `ProjectId`, шаблон серии и цели следующих недель (P4), `GoalSessions.Create` — шаг проекта (P2–P3), `CopyForWeek` (P7).

- Тесты: unit на каждое правило S, P, C и крайние случаи К1–К3, К7–К11, К16–К19, К22–К27; API на перенос шага в день и на другую неделю.
